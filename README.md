# 🍽️ SmartBite – Restaurant Menu Management System

SmartBite is a web-based Restaurant Menu Management System designed to make food browsing, menu management, and online ordering simple and user-friendly. It provides an attractive interface where users can explore food items, view prices, and add items to their cart.

## ✨ Features

* 🍔 **Food Menu Display** – Browse different food items with images, prices, ratings, and preparation times.
* 🥗 **Food Categories** – Explore vegetarian and non-vegetarian food options.
* 🔍 **Menu Filtering** – Find food items based on available menu filters.
* 🛒 **Shopping Cart** – Add food items to the cart and manage quantities.
* 💰 **Automatic Total Calculation** – Calculate the total price based on selected items.
* 📱 **Responsive Design** – User-friendly interface for different screen sizes.
* 🍕 **Interactive UI** – Simple and attractive restaurant ordering experience.

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive layout
* **JavaScript** – Interactive features and cart functionality
* **Node.js** – JavaScript runtime environment
* **Express.js** – Backend server framework
* **MongoDB** – Database (for storing menu and order data, once integrated)

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/arunatamilarasu58-cpu/restarurant-menu-management-system.git
```

### 2. Navigate to the Project Folder

```bash
cd restarurant-menu-management-system
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Server

```bash
node server.js
```

### 5. Open the Application

Open your browser and visit:

```text
http://localhost:3000
```

*If your server uses a different port, replace `3000` with the port configured in `server.js`.*

## 🛒 How to Use

1. Open the SmartBite website.
2. Browse the available food items.
3. View the prices and food details.
4. Add your preferred food items to the cart.
5. Increase or decrease item quantities.
6. View the automatically calculated total.
